## Getting Started for Contributors

1. Read the main [README.md](../README.md) for project overview
2. Review [PROJECT_STRUCTURE.md](../PROJECT_STRUCTURE.md) for folder organization
3. Start with [FRONTEND.md](./FRONTEND.md) or [BACKEND.md](./BACKEND.md) based on your focus area
4. Check [DATABASE.md](./DATABASE.md) for data models
5. Review integration docs ([STELLAR.md](./STELLAR.md), [KYC.md](./KYC.md), [PAYOUT.md](./PAYOUT.md)) as needed

## Documentation Standards

When contributing to documentation:

- Use clear, concise language
- Include code examples where applicable
- Keep examples up-to-date with the codebase
- Use proper Markdown formatting
- Add table of contents for long documents
